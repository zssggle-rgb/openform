# 资料导入导出

E11 提供服务端迁移能力。页面入口在 E08 接入，实际联动归入 Q4 的一次 QA；当前不声称运行验收完成。

教学资源包 `openform.resource/1` 保存指定固定版本或全部固定版本的页面、协议和评分配置，不含学生记录。导入后创建独立草稿，保留来源版本材料；切换来源版本会更新草稿，必须重新试做才能发布，不继承旧试做凭据。

课堂档案包 `openform.archive/1` 保存一个课堂的固定活动版本、全部最终提交尝试及其图片、原参与标识、显示姓名、回执和导出时的资料代次。进度与未提交草稿不属于档案。导入后建立只读历史档案，不绑定当前校园学生，不进入当前课堂统计，不重新开课。档案可查看、再次导出、按明确授权交接或删除。

导出提交后先显示排队任务；后台持久化快照、生成并校验文件后才显示可下载。任务与下载都核验发起者、当前空间和对象权限；课堂删除或代次变化、档案删除、成员停用、资产交接会阻止旧持有者下载。工作进程以任务代次防止过期回写。相同操作键重试返回同一任务。

上传采用 `PUT /api/workspaces/{space}/transfers/uploads/{requestKey}`，请求正文为 ZIP，不使用 multipart。预检完整路径清单、大小和 SHA-256，验证活动协议及图片后返回摘要。教师必须核对包类型、来源、版本、记录和图片数量，提供预检摘要对应的文件哈希并明确确认提交。预检不创建活动或档案；上传响应丢失可按操作键查询，确认响应丢失可用原输入重试，不重复创建。此哈希只证明包内一致性，不证明来源可信，教师仍须检查内容。

包使用 `index.json`、`content.json` 和声明的 PNG/JPEG 图片，不解压到用户提供的路径。拒绝路径穿越、目录、链接、加密、嵌套包、额外文件、重复路径和完整性不符。每包最多 20 MiB 压缩、100 MiB 展开、50 MiB JSON 正文、500 个文件、50 个版本、10000 份提交；单份答案 64 KiB、5 张图片，单图 10 MiB/4096 像素且单帧。超过边界返回明确失败，不生成部分成功包；当前课堂档案按整个课堂导出，没有记录子集导出。只支持上述 OpenForm 格式，不声明支持 QuickForm 历史包或未知 QFLink 格式；普通页面包导入另见制作说明。

下载文件默认保留 24 小时，未确认的预检保留 1 小时。文件保存在私有卷，不能通过公开静态地址访问。实例 `OPENFORM_WORKSPACE_TRANSFER_BYTE_QUOTA` 默认每空间 500 MiB，以保留压缩包及导入记录/版本的逻辑字节核算，不能当作物理磁盘大小保证。每空间最多 20 个待处理导出、10 个待确认预检；服务端限制同时预检数量，磁盘不足拒绝上传。

后台每小时清理过期文件、失效任务和超过空间保留期的历史档案。先使数据不可读，再清理文件；失败可重试。历史档案保留期限从导入创建时间起算，使用空间资料保留规则。教师已下载的副本和实例备份无法召回。迁移 `0011_transfers` 使用 RLS 和最小任务调度权限，worker 必须挂载私有文件卷。

接口包括 `/exports` 的创建、列表、详情和 `/{id}/file`，`/imports` 的列表、详情与 `/{id}/commit`，活动 `/{id}/imported-versions` 及版本 `/{number}/restore`，以及 `/archives` 的列表、详情、图片和删除。实例安装、备份恢复属于 E12，不由迁移包替代。

遵循用户要求，不新增或运行自动化测试；逐任务一次源码 review，界面集成后一次 Q4 QA。

## 已实际走通

| 主流程 | 观察结果 |
|---|---|
| 注册与个人空间 | 新账号取得自己的个人空间，个人班级实际保存到服务端 |
| 校园开通与邀请 | 运维开通合成学校，管理员接受绑定邀请；管理员邀请教师，教师接受后保留个人空间 |

| 学生个人码 | 教师发码，学生验证后显示自己的姓名和编号，刷新仍为同一身份 |
| 换码与撤销旧身份 | 管理员重置码，旧学生会话刷新后回到码入口；旧码被明确拒绝，新码对应原学生 UUID |
| 换班与改名 | 换班、改名后仍为同一个学生 UUID，学生刷新看到更新后的姓名；原班级不再包含该学生 |
| 共用设备退出 | 学生退出后显示空码输入表单，上一位学生的姓名和编号不再显示 |
| 身份与空间导航 | 修复后退出班级详情清除旧地址；换空间进入对应工作台；刷新已选校园班级详情保持正确空间 |
| 移动端及控制台 | 学生入口与已验证身份页在 375px 可用；登录规则修复后控制台无该正则异常，合法/非法登录名的浏览器校验均有效 |

## Key Interactions to Verify

1. 教师在个人空间和校园空间分别制作活动；同校第二教师可以复制发布资源，但不能读原课堂学生记录。给协作制作权也不会自动授予课堂记录访问。
2. 自然语言生成、词汇样板、受支持 HTML 导入都在真实隔离页保存→读取→提交。只有服务器回执与教师确认齐备，当前修订才能开展；修改草稿不能改变旧课堂。
3. 两个真实浏览器/设备参加同一课堂：进度持久化、退出后恢复、重复提交只记一次、再做保留前次历史、教师统计可对账。
4. 教师暂停、恢复、结束；学生页面即使尚未轮询到新状态，也不能绕过服务端限制。已提交但丢响应的学生在结束后仍可验证身份找回原回执。
5. 校管建立任课、重发学生码、停用成员、交接活动；所有相关旧会话及时失效，个人空间与历史署名不丢失。没有合格接收人明确失败。
6. 诊断显示确定性统计、实际分析覆盖和可打开依据；教师复核属于该份报告；共享只显示教师发布的内容，之后新提交不自动混入。
7. 删除源记录，旧报告、精选共享和导出同时不可再访问；正在运行的旧分析不能重新发布被删内容。
8. 资源包往返不夹带学生数据；课堂档案导入为只读历史、不关联当前同名学生；下载在授权撤销后拒绝。

## Edge Cases

- 输入为空、只有空格、中文长标题、同名活动/学生、无答案标准、无人参与、只有进行中、1 万历史记录；无已知人数不显示 0% 完成率。
- 100 次相同操作键/同载荷得到同一回执；同键异载荷冲突；不同键同 attempt 不新增最终提交。断响应后查询结果，不能只看按钮禁用。
- 两设备分别先保存、先提交；暂停/撤销分别先于和后于提交；删除分别先于和后于报告发布。用屏障固定顺序，保存事务证据。
- 新学生加入/学生调出不改写课堂计划名单；额外参与单列，小组按记录员单元统计。不同学校个人码互不通用。
- 图片 0/1/5/6 张，10 MiB 前后边界、4096/4097 像素、伪 PNG/JPEG、磁盘满、上传成功但提交失败、他人文件 ID。
- 恶意 HTML 试图读宿主、冒充 message、外网请求、自行导航、嵌套 frame、携带 cookie；恶意 ZIP 路径穿越、压缩炸弹和不支持版本。不得出现业务凭据或学生数据外传。
- 模型拒绝/429/超时/空输出/格式错误/伪造依据；3/10 批成功；worker 执行后失租；费用结果未知不能显示已准确结算。
- 慢网、离线、刷新、后退、多标签、离开后返回、会话到期、共享设备换人；本机未确认输入与服务端已确认状态分开，登出清除上一身份可读缓存。
- 390px、768px、1280px 和桌面宽度；键盘弹窗关闭返回原对象、无整页横向溢出、导航折叠/角色切换、固定版本与筛选保持。

## Critical Paths

| GAP | 门槛 | 需要保留的证据 |
|---|---|---|
| G1 | 个人/校园/管理员/学生/运维的允许和拒绝矩阵 | API 请求与状态、无敏感正文的审计关联 ID |
| G2 | 三种制作方式→真实试做→发布，三类教学活动；生成质量与隔离 | 活动版本/协议/试做回执、网络记录、真实模型评估样本 |
| G3 | 真实 DB 竞态、重试、断回执、唯一最终提交 | 两种执行顺序、DB 记录数和原回执 |
| G4 | 图片/资源/档案失败恢复及受控下载 | 预检结果、文件校验和、越权拒绝、无半导入状态 |
| G5 | 模型任务、覆盖/依据、配额及删除失效 | 任务代次、调用状态、报告快照 ID、费用不确定状态 |
| G6 | 校园成员/任课/调班/交接全生命周期 | 同校两教师和同名学生对照结果 |
| G7 | 干净 Linux 安装/升级/断公网课堂/旧备份锁定恢复 | 镜像 digest、迁移结果、恢复演练和重授权记录 |
| G8 | 500 人负载、三浏览器和真实课堂 | 原始指标、环境、p99/新鲜度、设备网络和教师反馈 |

负载按工程方案：10×50 人、30 分钟、每生每 5 秒保存/状态读取、500 次提交集中 5 秒并加同秒突发；另测图片/导出/模型故障共存。正常提交 p99 ≤2 秒、摘要 ≤5 秒是目标；数据库故障时检查无假成功、恢复后可对账。浏览器自动化覆盖 Chromium/Firefox/WebKit，真实学生手机/平板另测。

模型评估使用固定合成样例和教师标注基线，比较生成可运行性、字段匹配、题意、引用正确性、实际覆盖、成本；提示词/模型版本变化必须重跑，越权或伪造依据硬失败。现场验收覆盖 3–5 位教师、1 位管理员、3 类活动、5–10 节课；自主复用和教学改进行为据实记录，不预填结果。

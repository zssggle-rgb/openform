## 本轮真实浏览器走查

使用 Codex 内置浏览器的独立教师、学生、另一教师标签页；没有用直接写 localStorage 的方式替代 UI 操作。

1. 新建“整合验收 · 词汇课堂” → 三题试做 → 保存进度 → 试做回执 → 教师检查固定版本 → 班级开展。新课堂 0 人、试做不计入正式数据。
2. 学生 DEMO-001 进入正确课堂，保存第一题后教师显示参与 1、完成 0、提交 0。暂停接收后保存被拒绝；恢复后原答案可继续保存。
3. 学生提交后教师显示参与 1、完成 1/3、提交 1。学生回执与教师原始作答弹窗显示相同回执，第三题文字一致。
4. 教师开放本人反馈后学生端出现教师文字；共享预览发布后学生 S05 显示发布版本 1、固定范围 1 人。生成诊断后进入对应 T07，覆盖人数一致。
5. 教师重置 s1 个人码，学生原标签页立即显示身份失效；使用班级页的新码进入，仍找到同一份旧回执与本人反馈。
6. 新建“整合验收班”、指定陈明任课、添加一名合成学生；陈明标签页 T08 显示该班、学生 1、任课陈明。陈明复制校内资源后 T01 显示独立副本及 0 个固定版本。
7. 教师创建导出任务后到 T12 可找到结果。通过真实文件选择器导入测试资源包，跳到“资料迁移验收 · 实验探究”独立草稿。
8. 修改草稿后点击离开，显示未保存处理弹窗；取消后保存，刷新仍为修订 2，目标文字保留。
9. 课堂入口二维码渲染成功且指向当前课堂；没有包含个人码。未验证真实手机扫码接入，回环地址仅用于本机。
10. 教师 C03 和学生 S03 分别实测 1440 / 1024 / 768 / 390 / 320 px，共 10 次尺寸检查，`scrollWidth <= innerWidth`。检查了教师桌面和 320px 名册、学生 390px 回执实际截图。

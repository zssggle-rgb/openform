# 校内资源发布与复制

有效校园教师在活动详情中选择已真实试做并发布的固定版本，再发布到校内资源库。仅活动拥有者或被明确授予 `resource.publish` 的协作者可发布。标签和原发布者随固定版本保留；个人空间没有校内库。

本校有效教师按名称、学科、年级查找并预览资源。预览仍在隔离运行域中，只展示页面，不持久化作答，不产生接入验证证明。复制指定版本后直接打开自己的独立草稿，需重新真实试做、确认内容、发布，才能开课。

复制只携带页面、静态资产、题目、评分标准及数据约定，不携带名单、学生记录、进入码、对象协作授权或原教师课堂。复制凭据按空间、账号和操作键绑定；超时保留原操作键，可用“恢复上次复制”读取或重放原结果，防止重复创建活动。

资源发布者或学校管理员可撤回。撤回阻止新预览与新复制，不删除已有副本、课堂或学生回执。源发布新版时，活动列表提示来源已更新；已有副本不会被覆盖。学校管理员只有资源管理职责时仍不能读取课堂记录或复制为教学活动。

E10a 为校内复用部分，校园成员交接、生命周期、配置额度另在 E10b 实现。源码评审与 Q3 真实浏览器验收分别记录；本文不代表现场教学验收。

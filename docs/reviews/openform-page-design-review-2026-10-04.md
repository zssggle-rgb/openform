## 初审

Step 0 初始总体印象：7/10。主要功能清单完整，活动、课堂、资源、档案分界正确；但页面拆分偏多，首次开通和进入路径留有空白，状态表缺少完整成功/等待路径，窄屏和键盘行为尚未落到具体页面。

本轮的完整目标：每个角色能找到起点，完成一节课与校园协作，有可执行的返回和恢复路径；页面划分明确、状态不误导、角色切换不暗示越权、已定风格有可沿用的组件规则。评分评价方案覆盖，不等于产品或教学效果得分。

## 七项检查记录

### Pass 1：信息架构

初始 7/10。R1–R6 已纳入方案：减少重复入口，补首次使用，定义开展/进入默认路径，明确实时课堂与快照报告的阅读顺序。最终 9/10；文档结构已明确，仍须通过后续完整原型验证真实教师是否能独立完成任务。

### Pass 2：交互状态

初始 6/10。R5、R7、R8 补齐加载、空态、失败、成功、部分状态，覆盖保存、图片、提交、模型任务、资源复制与权限失效。最终 9/10；成功标记都有可观察依据，原型和后端仍需实现验证。

### Pass 3：用户旅程

初始 7/10。已把既有需求转为教师、学生、管理员三条故事板，并标注首次进入、开展、等待提交、判断结果、再次复用时的期望与担忧。R4–R7 解决故事板中实际断点，未重复计算决策。最终 9/10；感受是设计假设，尚无现场访谈/课堂观察。

### Pass 4：通用模板化风险

初始 9/10，最终 9/10，未发现需要改变视觉方向的新问题。模式：制作、课堂、校园、学生为 OPERATE；报告的阅读部分兼具 READ，不使用营销落地页规则重做界面。现有紫色和紧凑中文字体由用户明确选定，不因通用偏好改色或把教师正文统一放大到 16px。

| 硬拒绝项 | 命中 | 依据 |
|---|---|---|
| 首屏通用 SaaS 卡片网格 | 否 | 列表、制作区、题目或接收概览作为主内容 |
| 图美而品牌不明 | 否 | 正式 SVG Logo 与当前学校/活动上下文 |
| 大标题没有清楚动作 | 否 | 新建、试做、查看课堂、验证进入等对应任务 |
| 杂乱图像压在文字后 | 否 | 无装饰背景图 |
| 多区块重复情绪口号 | 否 | 功能标题与数据说明，无营销文案 |
| 无叙事目的轮播 | 否 | 无轮播 |
| 卡片堆叠替代工作区布局 | 否 | 工作台使用表格和分区，学生使用单个阅读容器 |

| Litmus 检查 | 结论 | 依据 |
|---|---|---|
| 首屏可识别产品/品牌 | YES | 正式 Logo、空间与活动名 |
| 有单一主要视觉中心 | YES | 当前任务内容和对应主动作；不是装饰图 |
| 扫描标题能理解页面 | YES | 我的活动、课堂详情、教学诊断、输入个人码等 |
| 每个区块只有一个工作 | YES | 实时记录、规则统计、模型解释、接收检查分别分区 |
| 面板是否有必要 | YES | 用于编辑/预览边界或单列参与区域，没有营销卡片网格 |
| 动效是否改进层级 | NO | 线框未制作动效；方案仅保留既定短过渡，不为评分新增动画 |
| 去掉装饰阴影仍清晰 | YES | 基于内容、字级与边界，常规区域不靠阴影 |

上述是主笔对文本与六个结构线框的判断，没有外部模型共识，也未覆盖每个页面的最终视觉。

### Pass 5：设计系统一致性

初始 7/10。R9 给新增组合写明 token 和已有组件的对应关系；不新增字体、品牌色、圆角层级或装饰模式。最终 9/10。复用 `DESIGN.md` 的桌面 14px 正文/13px 表格及学生 16px 正文是遵循用户确认方向；移动表单与触控按学生/触控规则放大。

### Pass 6：响应式与无障碍

初始 5/10。R10 明确三个断点下的工作区、表格、制作切换、全屏证据、学生输入/操作区，补标签键盘、弹层焦点、状态播报、减少动态效果和目标尺寸。最终 8/10；规则可供实现，尚缺完整原型、真实触控设备和辅助技术验证，任务内保留必做检查，不转成可选 TODO。

### Pass 7：未决设计事项

无评分。R1–R10 均按既有用户授权选 A 并写入方案，0 项尚待用户决定，0 项新增功能后置。最终路由、认证实现、名单及权限接口、状态持久化和容量属于工程任务；本次不把这些宣称为已实现。保持已有三个后续候选，不新增设计债 TODO。

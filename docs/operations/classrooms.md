# 活动版本与课堂

E05 接入教师样板、隔离试做、固定版本、课堂、进度、最终提交、本人历史和规则统计。应用数据库版本为 `0005_classrooms`。教师从“我的活动与课堂”选择样板；试做完成真实保存、回读和提交，核对题目与答案标准后发布。课堂只引用固定版本。

班级课堂第一次开课冻结名册。后续调班不改变计划人数，获准新加入的参与者计入额外完成；小组课堂按指定记录员计数。快速课堂的计划人数和完成率为未知，临时身份只适用于进入的课堂，不能凭称呼找回其他人的历史。小组配置由创建课堂 API 接收，完整制作与小组配置界面在 E06/E08 接入。

保存使用预期进度版本，版本冲突要求先读取。每次尝试最多一条最终提交；明确重新作答建立新尝试，保留原提交。重复操作的回执与请求摘要在同一事务持久化。宿主在发送前保留原操作，收到并核验回执才显示已保存或已提交；超时保留未知状态，恢复使用原操作键和原内容。明确拒绝的操作清除待确认项，继续读取当前状态。退出、身份失效和换人清除当前设备的待确认内容；服务端已接收回执仍可通过本人历史读取。

课堂暂停或结束拒绝新保存、事件和提交，但已接收原操作的回执可找回。课堂状态与写入在事务中共享课堂锁。统计只计算最近一次最终提交，事件和保存不计完成；未配置标准或没有回答的可选题不虚构正确率。校内活动使用授权不授予课堂记录读取权。

E07 尚未集成时图片请求明确返回未接通，不能将图片字段登记为已接收。模型生成、模型归纳、资源共享及生命周期等按后续任务交付。

本任务按用户要求不新增或运行自动化测试。逐任务一次 `/review`，E04/E05/E07 集成后执行一次 Q2 课堂主流程 QA；源码实现、合并、部署和 QA 分开记录，当前文档不证明 Q2 已通过。

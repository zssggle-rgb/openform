使用线上测试环境、合成教师/学生数据；记录实际部署 revision。每项修改开发后一次 `/review`，同轮处理发现；8 项修改集成后执行一次本清单。教师桌面 1440×900，学生窄屏 390×844；这些是本轮复查尺寸，不代表完整浏览器/设备矩阵。

检查业务内容与操作结果，不把 HTTP 成功、模型调用完成、页面数量或后台字段完整当作用户可用。

## Key Interactions to Verify

1. 新教师由空活动进入制作。要求生成 apple=苹果、book=书、water=水三道选择题，以及选项 1/2/3、答案 2 的一道 `1+1` 选择题。内容满足要求并能看预览；完成真实试做保存、刷新恢复、最终提交、内容确认、发布。F01 不以提示改成成功就算关闭。
2. 修改已创建活动的题目内容或答案后重新试做发布；旧发布课堂保持原内容。制作页不要求教师理解任务、协议或原输出；题目与预览成为主体。
3. 词汇快速课堂、名单测验课堂与实验课堂分发专属链接。实际打开/扫码后不用再次手输课堂码；个人身份验证后仍定位原课堂，临时参与者以称呼进入。打印预览卡显示正确课堂名称、定位码、链接/二维码。
4. 学生选择答案，保存后刷新恢复；最终提交后教师可看到同一作答。390px 答题页的主体是题目；已保存/已提交反馈清楚，没有通信、服务端版本或回执 ID。暂停时点击提交，当前失败反馈可见，恢复后原输入仍可提交。
5. 实验路径添加合成图片、40℃/30 秒观察与文字，回到活动并提交；教师看到对应数值、单位和加载完成图片。不能以图片 URL 存在代替实际加载。
6. 快速课堂仅显示适用的参与、已交、未交与题目表现；不显示缺席或无分母完成率。名单课堂有一位已交、一位未交时可定位真实学生，状态来自该次课堂。已交学生开始再练后，不被误记为从未提交。开放题不编造正确率，未答不归为答错。
7. 对有真实提交的词汇及测验课堂生成诊断：完成后不刷新浏览器就能看对应报告。点击依据显示学生称呼、题干、学生答案、标准和时间；不显示原始 JSON。复核后状态更新；教师填写并共享摘要，学生只见确认内容；撤回后旧共享不可见。
8. 学生历史显示活动名、业务状态与真实时间，继续/查看打开对应原记录。换一位同学后不沿用前一位参与上下文。个人班级界面只显示名单和相应动作，不显示学校任课配置说明。

## Edge Cases（在同一次主流程中核对）

- 生成失败或模型配置不支持输出格式时，保留要求、已有草稿和原发布内容，给出可执行的业务恢复动作；不自动启动额外收费调用。
- 草稿改动后旧试做/确认不得继续发布新草稿。
- 诊断正在读取时切换课堂，迟到结果不能显示在新课堂；报告读取失败只能重读原报告，不重复生成。
- 实际没有名单、标准或已知时间时，不把未知写成零、答错或伪造完成时间。
- 课堂结束/权限失效按现有服务端规则处理，页面不假报成功；依据使用原报告引用，不用后来草稿或提交冒充旧依据。
- 剪贴板失败仍可手选链接；二维码/卡片不包含个人进入码、CSRF、会话凭据。
- 样板页面文案修改用于新版本，不偷偷重写旧发布包。旧版本兼容与新版本 UI 验收分别记录。

## Critical Paths

```text
教师要求 -> 新草稿 -> 修改 -> 预览 -> 真实试做 -> 发布 -> 开课 -> 专属入口
                                                                    |
学生进入 -> 作答 -> 保存 -> 刷新恢复 -> 提交 -> 教师结果 -> 诊断同页可见
                                                        |
                                               业务依据 -> 教师复核 -> 学生摘要/本人历史
```

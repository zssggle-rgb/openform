# OpenForm 整合原型

将 23 个独立设计页组织为同一个交互原型，沿用 `DESIGN.md`、正式品牌资产和已确认的页面职责。入口是 [index.html](index.html)，需要通过 HTTP 服务打开，不能双击为 `file://`。

## 启动与检查

在仓库根目录运行：

```sh
python3 -m http.server 8772 --bind 127.0.0.1
node prototype/check.mjs
node --test --experimental-test-coverage prototype/tests/*.test.mjs
```

浏览器访问 <http://127.0.0.1:8772/prototype/#G01>。无需安装 npm 依赖或构建。Chrome、Edge 和 Codex 内置浏览器可使用本地 Web Locks 完成多标签页顺序保存。

## 演示身份与完整旅程

| 入口身份 | 初始范围 |
| --- | --- |
| 林知夏 | 学校教师兼管理员；七年级（1）班；另有个人空间 |
| 陈明 | 学校教师；七年级（2）班 |
| 周管理员 | 纯校管，没有课堂答卷权限 |
| 学生 DEMO-001 / 002 / 003 | 第一班，其中两位同名学生有不同稳定标识 |
| 学生 DEMO-004 | 第二班 |
| 独立运维 | 从演示入口折叠区进入；本机快照演示 |

以上都是可重置的合成身份，账号选择仅用于演示。重置个人码后以班级页显示的新码为准。

1. 林老师进入“我的活动”，新建草稿，编辑后保存。
2. 进入“试做与接入检查”，完成三题并收到试做回执。返回确认内容，固定版本。
3. 开展活动，选择班级个人码或快速临时参与。新课堂初始人数为零。
4. 在“学生参与入口”中用新标签页打开学生页面。班级活动输入个人码；快速活动填写称呼。
5. 学生保存进度，教师仅看到参与和进行中；学生最终提交后，双方显示同一回执。
6. 教师查看原始依据、生成固定诊断示例、设置本人反馈、预览并发布共享结果。
7. 校管新建班级、加学生和指定任课；另一位教师可在自己标签页的班级列表看到结果。
8. 发布或复制校内资源，副本出现在“我的活动”。资料导入/导出在“资料迁移与档案”找回。

## 代码边界

- `model.mjs`：不可变活动版本、课堂与尝试归属、权限演示、回执幂等、统计、报告/共享快照、名单任课、资源迁移与恢复。
- `store.mjs`：持久化成功后再返回结果；Web Locks 串行写入；`storage` 事件同步其他标签页。会话身份在 `sessionStorage` 中独立保存。
- `app.mjs`：路由、工作台框架、统一弹窗、事件处理、未保存离开、文件适配。
- `teacher.mjs` / `admin.mjs` / `student.mjs`：三端页面；`ui.mjs` / `icons.mjs`：共享呈现与已确认图标。
- `base.css` 从原单页设计复制，`integrated.css` 适配整合状态与导航；Logo 和 favicon 直接引用仓库正式 VI。
- `vendor/qrcode.js` 是原单页使用的二维码库，许可单独保留。二维码不含学生个人码。

## 与产品实现的区别

所有数据保存在当前浏览器的 localStorage，所有测试只用合成数据。权限判断用于体验演示，不是服务端安全边界，也不应填入真实学生材料或密钥。不同浏览器或设备不会共享数据，127.0.0.1 链接不能给学生手机接入。

想法创建使用三类结构化样板，诊断是标注过的固定示例归纳；没有调用模型。HTML 导入保留原文并在禁脚本、禁同源、禁外部资源的 iframe 中预览，课堂使用重新试做过的结构化题目，不代表已经具备任意网页接入协议。图片会压缩为长边不超过 900 像素的本机预览，不上传、不参与 AI 分析。

备份恢复只是本机快照，不是数据库备份：恢复后课堂关闭、共享撤回、旧个人码失效，需重新发放。现有单页设计稿保持原样，原型不替代后端开发、真实学生设备、校园网络、读屏或恢复演练验收。

## 数据与重置

状态键为 `openform-integrated-v1`，每个对象通过空间、活动、课堂、学生和尝试标识关联。刷新保留已确认内容；退出仅清除当前标签页身份和未确认草稿。可在 G01 的“原型工具与独立运维”中重置本浏览器的合成数据。

测试覆盖与实际浏览器证据见 [本轮记录](../docs/reviews/page-integration-2026-10-05.md)。没有运行过的验收项保持待验，不把原型中的成功提示算作产品服务端验收。

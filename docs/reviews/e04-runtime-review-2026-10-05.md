## 审查与修正

主审发现初版 AJV 在浏览器执行 schema compilation，需要 Function constructor，与宿主 `script-src 'self'` CSP 冲突，真实接入会失败。已在本次审查中改为构建时用 AJV standalone 生成校验代码，并通过 esbuild 打包其依赖；浏览器只执行生成的验证函数，不放开 unsafe-eval。每次 dev/build 从同一套 E01 schema 重新生成，产物不进入版本管理。

原生 reviewer 已读取包含以上修正的代码，未发现可操作 P1/P2 问题。主审核对了空间事务/票据撤销的锁顺序、不可变包的权限、每次导航关闭旧端口与请求、nonce/source 检查、消息能力与大小/速率限制、SDK 未确认结果、独立域名与 no-access-log、构建资源复制及 CI 范围映射。

本轮没有未处理审查问题。有审查内修改，不以一次修改后的局部检查宣称额外完整复审已经收敛。PR CI 只执行已有格式、类型和编译步骤，测试及镜像 job 默认不运行；不再在合并后重复 main CI。

# 三端应用页面

E08 将前期分批接入的业务能力整理为可直接打开与刷新恢复的真实页面，沿用 DESIGN.md、正式 Logo 和浅色紧凑工作台。手机提供可展开工作区导航，学生保持单列、大字号与大触控目标。交互原型仅作为设计参考，不部署到 QA。

| 入口 | 实际业务内容 |
| --- | --- |
| G01 | 账号登录、注册、验证邀请与加入实际获准空间 |
| G02 / C06 | 空间规则、保留期限、累计额度和模型开关；普通教师只读，校管/个人拥有者可配置 |
| T01 | 我的活动列表，已加载活动搜索和发布状态筛选 |
| T02?activity= | 活动详情、固定版本、协作授权、资源发布、资源导出和开展课堂 |
| T03 / T04?activity= | 同一制作器及真实试做；T04 为兼容入口，不创造第二种活动 |
| T05 | 我的课堂及开停状态 |
| T06?classroom= | 学生入口、接收状态、确定性结果、最终记录与图片、授权、档案导出和结束后删除 |
| T07?classroom= | 诊断快照、任务恢复、证据、教师复核与明确共享 |
| T08 / T09?class= | 班级与名单、稳定学生个人码；校园管理维护任课关系 |
| T10 / T11?resource= | 校内资源发现、固定版本预览、独立复制与撤回 |
| T12 / T12?archive= | 迁移任务、预检确认、受控下载；受限只读历史档案、图片及删除 |
| C01 / C02 / C03 / C04 | 成员邀请/角色/停用、班级任课、学生名册、同源校内资源管理 |
| C05 | 逐项资产交接及管理审计，只读管理元信息，不因此可查看学生答案 |
| S01 | 验证个人码或本次快速身份，再进入课堂 |
| S02?classroom=&attempt= | 作答、进度、图片和持久化提交 |
| S03?classroom=&attempt= | 具体尝试的真实回执，原尝试保留，开始新尝试另行确认 |
| S04 | 本人的已保存进度及最终历史；按具体尝试打开，不用最近一次回执冒充旧回执 |
| S05?classroom= | 教师明确发布的摘要；没有开放摘要时不展示此入口 |
| O01 | 独立运维凭据登录，查看实例维护/恢复锁、备份核验与后台任务；备份恢复由部署主机受控命令执行，不能用学校管理身份替代 |
| /guide.html | 无需登录的 HTML 最终用户说明；先介绍软件，再按教师、校园管理员、学生分章，顶栏在新标签页打开，保留当前页面 |

校内协作教师选择接口只在对象所属教师查授权时提供同校有效教师的标识和名称，不开放管理通讯录、登录名或学生数据。课堂只获开停权而未获记录权时仍可管理接收；记录区域明确无权限，不显示零值。学生尝试详情逐项核验当前参与身份、空间与资料删除状态。

文件上传使用原操作键，未知结果不显示成功；导入预检可从服务端列表恢复。导出生成完成后才可下载，刷新与重新打开不依赖页面内假任务状态。失权后的新请求由服务端拒绝；已交付字节和下载副本无法召回。

源码交付及一次 review 不等于全部页面已通过运行验收。三端入口、迁移往返、交接与删除的主流程已在 [Q4 一次真实 QA](../reviews/qa-q4-2026-10-06.md) 中记录；只对失败步骤修复复查，没有新增测试或重复全量回归。新标签页先选择所属空间；同标签页刷新恢复已验证的空间选择。
